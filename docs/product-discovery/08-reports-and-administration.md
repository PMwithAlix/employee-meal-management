# گزارش‌ها و قابلیت‌های اداری

تمایز این سند:

- **گزارش:** تجمیع برای چاپ/مشاهده تعداد و فهرست سفارش
- **نمای عملیاتی:** جدول روز با دکمه حذف و افزودن
- **داشبورد:** وضعیت ورود فرد، نه KPI غذا
- **اداری:** مدیریت کاربر و منو

خروجی فایل (Excel/CSV/PDF سرور) پیاده نشده؛ چاپ از پنجره مرورگر است.

---

## R-01 سفارش ناهار روزانه به‌تفکیک دپارتمان

| مورد | مقدار |
|---|---|
| مخاطب | پشتیبانی |
| مجوز | `[Authorize(Roles = "پشتیبانی")]` |
| منبع | `GetDailyOrders` ← `FoodReservations` + `User` |
| فیلتر | `selectedDate` از نوار روز |
| گروه‌بندی | `Department` با `GetDeptOrder`؛ سپس ستون‌ها بر اساس نام غذا |
| سنجه | تعداد ردیف ناهار غیرخالی و غیرحذف‌شده؛ شام `Guards-` به‌عنوان ناهار با پسوند «شام شب» اضافه می‌شود |
| چاپ | `printSection('lunchOrdersSection')` A5 |
| وضعیت | Fully Implemented |

حذف ناهار از همین جدول عملیاتی است (گزارش خالص نیست).

## R-05 گزارش ماهانه تعداد وعده هر کاربر

| مورد | مقدار |
|---|---|
| منبع | حلقه `GetDailyOrders` روی `daysInMonth` |
| گروه‌بندی | `Username` |
| سنجه | `LunchCount`, `DinnerCount`, جمع؛ ردیف جمع کل |
| فیلتر ماه | دکمه‌های ماه قبل/جاری/بعد (سه ماه نسبت به امروز در `InitMonths`) |
| چاپ | بخش کامل؛ به‌علاوه ماتریس «ناهار کل ماه» و «شام کل ماه» |
| وضعیت | Fully Implemented |

ماتریس ماه: سطر کاربر، ستون روز شمسی، سلول نام غذا؛ جداول به‌ازای دپارتمان مرتب‌شده. حذف‌شده‌ها در شمارش ماهانه کنار گذاشته می‌شوند اما در ماتریس چاپ مقدار خام `Lunch`/`Dinner` (احتمالاً شامل متن حذف) نشان داده می‌شود. **Partially Verified** تفاوت شمارش و چاپ ماتریس.

## داشبورد (غیرگزارش غذا)

`Dashboard.razor`: IP ثابت، آخرین ورود، ورود فعلی، آخرین شکست. مخاطب همه نقش‌ها. متریک غذا ندارد.

## نماهای اداری

### A-01 مدیریت کاربران

مسئول دفتر. لیست، جستجو، CRUD، ریست رمز/IP. داده: `Users`. گزارش آماری کاربر نیست.

### A-02 مدیریت منو

پشتیبانی (ویرایش) / مدیریت (عمدتاً مشاهده). ورودی منو + نمایش امتیاز و نظرات. گزارش رسمی نیست.

### A-03 لاگ رزرو

جدول `FoodReservationLogs` نوشته می‌شود. صفحه گزارش لاگ **وجود ندارد**.

## فیلتر زمانی مشترک گزارش غذا

- ماه: فقط سه گزینه نسبی به ماه شمسی جاری (نه بازه آزاد و نه سال جدا)
- روز: تمام روزهای ماه انتخاب‌شده
- بازه دلخواه از-تا: پیاده نشده

متد `OnPersianDateChanged` در کد گزارش هست و به UI وصل نیست (مرده).
